# BCT Study Guide Dashboard

An interactive, responsive, and modern study guide dashboard for Blockchain Technology (BCT), covering Ethereum, Hyperledger Fabric, and Consensus & Tokenization mechanisms.

## ✨ Features

- **Data Integrity**: Contains the complete syllabus questions, answers, and keys exactly identical to the official guide.
- **Progress Tracking**: Tap checkboxes on cards to track your mastered items, with real-time percentage progress calculations that persist automatically inside local storage.
- **Multi-Level Filters**:
  - Full-text fuzzy search across titles, questions, answers, and bullet points.
  - Weightage filter based on marks (High Yield: 7+ marks, Medium: 5-6 marks, Low: 3-4 marks).
  - Exam session filters (e.g., Nov 25, May 25, Nov 24, etc.).
- **Clean Flat Light Theme**: Focus-optimized, clean documentation design following GitBook/Tailwind layouts, with responsive grids for mobile, tablet, and desktop views.

## 🛠️ Tech Stack

- **Framework**: React 18 (Vite Bundler)
- **Styling**: Vanilla CSS Variables (Flat documentation layout system)
- **Icons**: Lucide React

## 🚀 Getting Started

### Prerequisites

Ensure you have [Node.js](https://nodejs.org) (v18+) installed.

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/alokbhorunde/BCT.git
   cd BCT
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the local development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
